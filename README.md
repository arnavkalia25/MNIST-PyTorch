# MNIST Digit Classification using PyTorch

A complete end-to-end handwritten digit classification project built with PyTorch.

This project explores multiple deep learning approaches for classifying handwritten digits from the MNIST dataset, including a Multi-Layer Perceptron (MLP), Convolutional Neural Network (CNN), data augmentation, hyperparameter optimization using Optuna, error analysis, custom image prediction, and an interactive Streamlit application.

---
